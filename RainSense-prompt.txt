# Build RainSense AI — AI-Based Rooftop Rainwater Harvesting Assessment System

## 1. Project Objective

Build a complete, working web application called **RainSense AI**.

RainSense AI is an intelligent rooftop rainwater harvesting assessment and recommendation system. A user should be able to upload a rooftop image, provide basic rooftop and location information, and receive an AI-assisted assessment containing:

* Rooftop/obstacle detection
* Roof characteristics
* Rainfall information
* Estimated annual harvestable rainwater
* Rainwater harvesting readiness score
* Recommended storage capacity
* Recommended harvesting components
* Estimated installation cost
* Estimated savings
* Estimated payback period
* Explanation of why the system produced the score
* Downloadable PDF assessment report
* Assessment history

The application should look like a polished final-year/college project rather than a basic CRUD application.

# 15. Rainwater Calculation

Implement the standard runoff calculation:

```text
V = A × R × C
```

Where:

```text
V = estimated harvested water
A = effective roof area
R = rainfall depth
C = runoff coefficient
```

Make sure units are consistent.

If rainfall is given in millimetres:

```text
R_m = rainfall_mm / 1000
```

Then:

```text
volume_m3 = roof_area_m2 × rainfall_m × runoff_coefficient
```

Convert to litres:

```text
litres = volume_m3 × 1000
```

Create a separate calculation service:

```text
backend/app/services/rainwater_calculator.py
```

# 16. Runoff Coefficient

Use configurable coefficients.

RCC / Concrete → 0.80–0.90

# 41. Critical Instruction to the Coding Agent

Do not just generate a collection of disconnected UI screens.

Build a **fully connected working application**.

The frontend must communicate with the backend.

The backend must perform real calculations.

The database must actually store assessments.

The results page must use actual backend responses.

The PDF must contain the actual assessment data.

Do not hard-code the final dashboard values.

Do not fabricate AI predictions.

Do not claim live weather data when demo/cached data is being used.

Do not expose API keys.

If a dependency such as a custom YOLO model is unavailable, implement a clean fallback/demo mode and clearly label it.

Prioritize a stable end-to-end working workflow over unnecessary advanced features.

Before finishing, run the application, test the complete assessment workflow, fix errors, and make sure the project can be started using the commands documented in the README.

## Success condition

A user should be able to open RainSense AI, register, log in, upload a rooftop image, enter rooftop information and location, run an assessment, receive calculated rainwater potential and a transparent readiness score, view recommendations and charts, save the assessment, and download a professional PDF report.

Build the project incrementally and keep the code clean, modular, and production-style.
